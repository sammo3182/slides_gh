研究问题

纪律强制的团体活动有什么用？

能改变青年的什么？怎么改变的？

  • 毛泽东1937年为抗日军政大学题写的校训。
  • 习近平2023年2月7日，在学习贯彻党的二十大精神研讨班开班式上提出，推进中国式现代化是一个系统工程，需要正确处理好顶层设计与实践探索、战略与策略、守正与创新、效率与公平、活力与秩序、自立自强与对外开放等一系列重大关系。

青年政治社会化与中国特色制度

  • 大学是中国青年政治社会化的最后一站，也可能是最重要的一站
  • 高校政治社会化三条路径
    • 思政课程 → 课堂场域
    • 党团活动 → 有组织社会化：覆盖最广、制度化最高
    • 志愿活动 → 自愿性社会化：个体自主选择
  • 有组织社会化的两个特征
    • 组织性与纪律性：组织生活制度、要求成员参加、缺席须请假补学
    • 价值性：持续互动 → 与集体目标一致的认知与取向

习近平：人才培养体系贯通其中的是思想政治工作体系。 这一制度性社会化过程的实证研究，是理解中国高等教育独特运作逻辑的关键。

党团活动与志愿活动的关键差异在于组织化程度与纪律约束： 前者以章程与组织纪律为支撑，参与具有刚性；后者以主动参与为前提，选择空间较大。

以党团活动为代表的有组织社会化有效吗

理论张力悬而未决

支持视角 (Brady et al. 1995; Metz and Youniss 2005; Putnam 1993)

  • 制度化嵌入 → 降低社会化成本
  • 周期性仪式 → 价值内化
  • 社会资本 → 情感联结

怀疑视角 (Scott 1985; Huang 2015)

  • 强制性 → 心理抗拒、表演性顺从
  • 高频动员 → 认同疲劳
  • 家庭、社会力量竞争 → 效果不稳定

实证缺口长期存在

  1. 规范讨论多 → 实证检验少；国际研究聚焦欧美选举型、志愿型参与
  2. 焦点集中思政课程 → 参与式社会化被忽视
  3. 有组织 vs 自愿性社会化 → 未纳入同一框架比较

两类视角都有零散实证证据：基层选举、生态文明、英模宣传等场景， 但缺乏能同时容纳情感、行为、价值多层次结果的系统框架。

政治心理学分析框架：情感 → 行为 → 价值

  • 态度形成的三层递进结构 (Bandura 1977; 邹建平 and 肖唐镖 2022)
    • 情感：认同的心理起点 → 爱国主义 + 获得感/幸福感/安全感
    • 行为：认同的外在表现 → 制度化 vs 非制度化渠道偏好
    • 价值：认同的深层支撑 → 制度/政策/文化/道路认同
  • 行为认知机制：自我知觉 + 认知失调 (Bem 1972; Festinger 1957)
    • 反复参与 → 自我归因 → 态度重塑

象征性情感以爱国主义衡量，经验性情感以获得感、幸福感、安全感衡量， 后者对接十九大以来”三感”的政策话语。 四类价值认同与”四个自信”在结构上高度对应。

“行为先于态度”的微观机制为统一解释正向与负向证据分歧提供了视角。

研究假设

  • 假设1（有没有）：党团活动 → 情感 / 行为 / 价值认同 ↑（a）还是 ↓（b）
  • 假设2（什么样）：门槛效应（参与即显现）vs 累积效应（频次越高越强）
  • 假设3（谁更强）：自愿的志愿活动效应 > 纪律约束的党团活动 (Deci and Ryan 1985)
  • 假设4（谁受益）：体制外家庭学生获益更大 → 补偿性社会化 (Neundorf et al. 2016)

假设1为三组竞争性假设，分别对应情感、行为、价值三个维度。 门槛模式：一旦被卷入政治场域即产生初步认同提升； 累积模式：认同依赖持续观察、强化与重复接触。 假设3来自自我决定理论：内在动机驱动的自主参与应比纪律约束的参与更具塑造力。

研究设计

数据

  • T大学”学生基础调研”（2019–2023 五轮）
  • 院系分层抽样，每年约 10% 在校生
  • 重复横截面，N = 6135

解释变量：本学年活动参与频次（0 / 1–4 / 5–8 / 9–12 / 12+）

  • 有组织社会化：党组织活动、班团活动
  • 自愿性社会化：志愿活动

结果变量：11 个指标

  • 情感（4）：获得感、幸福感、安全感、爱国主义
  • 行为（3）：制度化 / 非制度化渠道偏好、制度化渠道占比
  • 价值（4）：制度、政策、文化、道路认同

模型

  • 混合效应模型（生源地 + 年份随机截距）
  • 门槛模型（五分类）+ 累积模型（线性频次）
  • 三类活动同入模型 → “赛马”比较
  • 活动 × 父母职业性质交互

控制变量：性别、学科、年级、党员/团员身份、学生组织成员、家庭收入、 父辈职业性质、父辈教育、家庭所在地、生源地区、高中类型。 情感与价值指标用 IRT-GRM 估计并转换至 0–1 区间。 二元渠道指标用混合 Logit，报告概率尺度平均变化。

门槛效应：参与即见效？

1–4 次 vs 0 次

  • 党组织活动
    • 爱国主义 ↑，获得感/幸福感/安全感
    • 制度化渠道 ↑，非制度化渠道
  • 班团活动
    • 四项情感全部 ↑
    • 制度化渠道 ↑，非制度化渠道
  • 志愿活动
    • 幸福感/爱国主义 ↑，获得感/安全感
    • 制度化渠道 ↑，非制度化渠道

低频参与者已在国家情感和制度化表达导向上表现出显著差异， 但党组织活动对非制度化表达的抑制在低频阶段尚不稳定。 党组织活动偏向国家情感与制度化表达，班团活动涉及更广泛的情感体验， 志愿活动则关联部分积极情感与制度化表达。

累积效应：越参与越认同？

频次每提高一级

  • 党组织活动
    • 获得感/爱国主义 ↑，幸福感/安全感
    • 制度化渠道 ↑ & 非制度化渠道 ↓
  • 班团活动
    • 四项情感全部 ↑
    • 制度化渠道 ↑，非制度化渠道
  • 志愿活动
    • 幸福感/爱国主义 ↑，安全感 ↓
    • 制度化渠道 ↑，非制度化渠道

党组织活动的”双向效应”是关键发现： 不仅提升制度化渠道偏好，还抑制非制度化渠道偏好， 这一双向性是班团活动与志愿活动均未达成的。

分类频次模型进一步显示，不同结果所需的参与强度不同： 爱国主义、制度化渠道在 1–4 次即显著； 非制度化渠道的抑制从 5–8 次开始； 获得感的提升主要出现在 9–12 次及以上。

稳健性：排除党员后党组织活动效应基本保持；排除团员后班团活动效应相对有限（见附录）。

价值认同：谁的塑造更全面

  • 党组织活动：四类认同全部 ↑，系数最高
  • 班团活动：四类认同 ↑，弱于党组织活动
  • 志愿活动：制度/政策认同 ↑，文化/道路认同


  • 梯度结构：政治内容越集中、组织嵌入越深 → 价值认同关联越广
  • 纪律性 ≥ 自愿性

无论组织性程度如何，持续的社会化实践均能在价值层面实现认同内化， 但党组织活动在全面性和一致性上表现出比志愿活动更明显的优势。 这与自我决定理论”自主参与更易内化”的预期相反。

调节效应：补偿性整合

  • 党组织活动 × 体制外家庭：获得感、政策认同边际收益显著更大
  • 其余结果及班团活动交互项 不显著

体制内家庭学生进入大学时已具备较高政治认同起点，边际提升空间有限； 体制外家庭学生从制度化教育中获得更大补偿。 党组织活动并非简单强化既有政治资源优势，而是在一定程度上弥补家庭政治社会化的资源差异。

总结与启示

  1. 有组织社会化稳定正向塑造认同，但重心不同：党组织活动 → 爱国主义、制度化表达、价值认同；班团活动 → 校园情感体验
  2. 门槛 + 累积并存：爱国主义、制度化表达低频即启动；获得感依赖持续参与
  3. 纪律性 ≥ 自愿性 → 效力取决于制度化深度、覆盖广度、持续可预期性，而非自愿/强制二分
  4. 补偿性整合 → 体制外家庭学生获得感、政策认同增益更大

实践启示：长期组织化参与平台 > 短期动员式活动；参与机会供给向体制外家庭学生适当倾斜
